# ✈️ Airline Flight Delay Analysis Dashboard

An interactive **Power BI dashboard** designed to analyze airline flight delays, airline performance, airport activity, and major reasons for flight delays.

## 📊 Project Overview

This project transforms airline flight data into an interactive dashboard that helps identify patterns in flight delays and compare performance across airlines and airports.

## 🔍 Key Insights

* On-time vs delayed flights
* Airline-wise flight performance
* Airport-wise analysis
* Major reasons for flight delays
* Delay trends and patterns
* Comparison of airline performance
* Interactive filtering for detailed analysis

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query**
* **Data Cleaning & Transformation**
* **Data Visualization**
* **DAX**

## 📈 Dashboard Features

The dashboard includes interactive charts, cards, and filters to make it easy to explore flight performance and delay-related information.

## 🎯 Project Objective

The main objective of this project is to practice **data cleaning, transformation, analysis, visualization, and dashboard development** using Power BI while generating meaningful insights from airline flight data.
